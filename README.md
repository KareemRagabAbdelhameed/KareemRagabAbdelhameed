## Featured projects

- **[Rydroo App](https://github.com/KareemRagabAbdelhameed/Rydroo_App)** — React and TypeScript frontend for searching and booking intercity trips in Egypt, with Arabic and English, maps, and card payments. [Live demo](https://rydroo-app.vercel.app)
- **[Rydroo App Backend](https://github.com/KareemRagabAbdelhameed/Rydroo_App_Backend)** — Express and MongoDB API for accounts, drivers, passengers, trips, vehicles, and Stripe payments.
- **[PriceChase](https://github.com/KareemRagabAbdelhameed/PriceChase)** — React and TypeScript shopping frontend for product search, price and rating filters, and wishlists. [Live demo](https://price-chase.vercel.app)
- **[Neurovox Frontend](https://github.com/KareemRagabAbdelhameed/Neurovox-frontend)** — React and TypeScript dashboard for investment plans, task missions, deposits, and withdrawals.
- **[iShare](https://github.com/KareemRagabAbdelhameed/iShare)** — React app for posting reviews and experiences across food, fashion, healthcare, and education.
